🚀 WASLNI — Animated Delivery Login UI

A modern and interactive delivery application login interface built using Flutter & Dart.

WASLNI is a Flutter UI project focused on attractive design, smooth animations, and a responsive mobile experience.

✨ Features

* 🎬 Cinematic animated hero image
* 🛵 Animated delivery icon
* 🎨 Modern dark theme with orange gradients
* 🔐 Email and password input fields
* 👁️ Password visibility toggle
* ✅ Client-side form validation
* ⏳ Animated login button with loading indicator
* 📱 Scrollable, mobile-friendly layout
* 🖼️ Custom local image assets
* 🌍 Arabic right-to-left interface

🛠️ Technologies

* Flutter
* Dart
* Material Design 3
* AnimationController
* AnimatedBuilder
* FadeTransition
* SlideTransition
* AnimatedSwitcher
* TextFormField and Form validation

🚀 Getting Started

1. Install Flutter and Dart.
2. Clone this repository.
3. Open the project in VS Code or Android Studio.
4. Add the required images to assets/images/.
5. Run the following commands:

flutter pub get
flutter run

🖼️ Custom Images

You can replace the images in assets/images/ with your own delivery, restaurant, and grocery photos.

Make sure the filenames match the paths used in the Flutter code.

⚠️ Authentication Status

This project currently demonstrates the login user interface and client-side validation only.

It does not include backend authentication, user accounts, or secure login sessions.

The loading animation is simulated for UI demonstration purposes.
